# Online Shop

Небольшой демопроект на Unity. Показывает применение адаптивной верстки на uGUI, Zenject и работу с REST API на примере внутриигрового магазина.

Логика интерфейса разделена по MVP. Для асинхронной загрузки используется UniTask, для анимаций DOTween. Список товаров использует виртуализацию и пул карточек для их повторного использования при прокрутке.

Демо включает две сцены: экран подключения и магазин. Приложение выполняет авторизацию на сервере, загружает каталог и баланс игрока, позволяет покупать товары за внутриигровую валюту и обрабатывает сетевые ошибки.

## Возможности

- Экран подключения с анимацией, индикатором прогресса и повторной попыткой при ошибке.
- Авторизация на сервере и повторная авторизация при истечении срока действия токена.
- Асинхронная загрузка сцены магазина, данных игрока и каталога товаров.
- Отображение названия, описания, иконки и цены товара, а также баланса игрока.
- Адаптивная сетка товаров и учет безопасной области экрана (Safe Area).
- Виртуализированный скроллер с пулом переиспользуемых карточек.
- Покупка товаров за внутриигровую валюту с обновлением баланса и каталога.
- Обработка сетевых ошибок и восстановление незавершенной покупки.

## Технологии

| Технология | Применение |
| --- | --- |
| Unity 6000.0.80f1 (Unity 6), C# | Движок и логика приложения |
| uGUI, TextMeshPro | Верстка интерфейсов, карточки товаров и текст |
| Zenject 9.2.0 | Внедрение зависимостей и управление жизненным циклом сервисов и презентеров |
| UniTask | Асинхронные операции и отмена задач |
| UnityWebRequest | Запросы по HTTP к серверу |
| Newtonsoft.Json, JsonUtility | Обработка данных в JSON |
| DOTween | Анимации интерфейса |
| ScriptableObject | Настройки сервера, пользователя, экрана загрузки и иконок товаров |

Пакетные зависимости указаны в [Packages/manifest.json](Packages/manifest.json). Zenject и DOTween находятся в `Assets/Plugins/`.

## Архитектура

Интерфейс организован по принципу MVP (Model, View, Presenter): модели хранят данные, представления работают с Unity UI, презентеры управляют поведением экранов. Зависимости связываются через установщики Zenject.

- **LogonPresenter** управляет подключением, прогрессом загрузки и переходом в магазин.
- **SessionService** получает токен сессии и отслеживает срок его действия.
- **NetworkService** выполняет авторизованные запросы данных игрока, товаров и покупок. При ответе `401` повторяет запрос после повторной авторизации.
- **SectionStorePresenter** загружает данные магазина и связывает интерфейс с сервисом покупок.
- **GoodsScrollPresenter** рассчитывает отображаемый диапазон товаров и обновляет содержимое карточек при прокрутке.
- **GoodCardPool** создает и переиспользует карточки, а **GoodsGridLayout** рассчитывает сетку и размер пула.
- **PurchaseService** управляет покупкой и восстановлением ее результата; незавершенный запрос сохраняется локально.

### Оптимизация скроллера

Количество карточек в пуле рассчитывается по размеру видимой области с запасом для прокрутки и ограничивается числом товаров. При прокрутке существующие карточки перемещаются и получают данные следующих товаров. Это позволяет отображать каталог без создания отдельного объекта интерфейса для каждого товара и уменьшает количество операций создания и удаления объектов.

При изменении размеров окна сетка пересчитывается с сохранением позиции просмотра.

### Структура кода

```text
Assets/Scripts/
├── Common/             # Общие утилиты
├── Infrastructure/
│   ├── Display/        # Параметры экрана и Safe Area
│   ├── Network/        # Запросы по HTTP, конфигурация сервера и DTO
│   └── SceneManagement/ # Загрузка сцен
├── Installers/         # Регистрация зависимостей Zenject
├── Logon/              # Экран подключения и его анимации
├── Player/             # Модель и сервис игрока
├── Session/            # Авторизация, токен сессии и индикатор подключения
└── Store/
    ├── Models/         # Данные товаров и результатов покупки
    ├── Services/       # Покупки и сохранение незавершенных запросов
    └── UI/
        ├── Configs/    # Настройки иконок товаров
        ├── Presenters/ # Логика магазина и скроллера
        ├── Scrolling/  # Виртуализация, сетка и пул карточек
        └── Views/      # Представления магазина и товаров
```

## Запуск

1. Клонируйте репозиторий проекта.
2. Клонируйте отдельный репозиторий сервера и запустите по инструкции в его README.
3. Установите **Unity 6000.0.80f1** через Unity Hub и добавьте папку проекта.
4. Откройте проект и дождитесь импорта ресурсов и установки пакетов.
5. В [BackendConfigLocal.asset](Assets/Configs/BackendConfigLocal.asset) укажите адрес запущенного сервера и пути API. В [UserConfigLocal.asset](Assets/Configs/UserConfigLocal.asset) задайте данные тестового пользователя. Эти конфиги подключены к `ProjectInstaller` в [ProjectContext.prefab](Assets/Resources/ProjectContext.prefab).
6. Откройте [LogonScene.unity](Assets/Scenes/LogonScene.unity) и нажмите **Play**. После авторизации автоматически откроется [MainScene.unity](Assets/Scenes/MainScene.unity) и начнется загрузка магазина.

Для работы демо требуется доступный сервер с совместимым API. По умолчанию в коде конфигурации заданы пути `/auth/login`, `/player`, `/items` и `/purchases`; фактические адреса определяются настройками `BackendConfigLocal`.
